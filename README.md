# WQMove（微信迁移）

ios微信聊天迁移

项目地址：https://github.com/xqwzka/wq-move

由 AI 制作，感谢原项目开源作者 [kolbicz](https://github.com/kolbicz)。

基于 [WQ Files](https://github.com/kolbicz/WQFiles) 的逃逸核心（`WQAccess` / `WQLaunchServices`，原样未改），界面全部重写。底层是 worse_query 沙盒技术，无需越狱、无需内核漏洞。仅支持 iOS 26.0–26.7.2 / 27.x；新版 iOS 随时可能让它失效。

## 使用方法

1. 点**需要迁移的微信**选来源：微信应用、`聊天记录`（临时存放）、`被覆盖的聊天记录`（备份）都可以当来源。
2. 勾选要移的聊天记录文件夹，可多选。
3. 点**移动到**选目标微信或 `聊天记录`，点**开始移动**，在确认页确认。
4. 移回去：来源选 `被覆盖的聊天记录`，点一个时间文件夹，勾选里面的文件夹，移到目标微信。
5. 主界面最下面的**检查更新**，点一下就查有没有新版本。
6. 局域网传输：A 手机来源选择聊天记录➡️目标选择另外一台手机；B 手机接收，选择目标微信或者聊天记录存放的文件里（后续需要在移动一次）。

## 同名处理

目标里已有同名文件夹时，先把目标那个文件夹整个移入文件应用里的 `被覆盖的聊天记录`，按移走的时间建一个文件夹（`备份 MM.DD日HH.mm.ss`，精确到秒）存放，原文件夹在里面保持原名；再把来源的文件夹移入。永远不会覆盖，也不会原地改名。`被覆盖的聊天记录` 在文件应用容器里，删本应用不消失。移动是真移动：移完后来源那边的文件夹消失。

来源和目标选了同一个位置时不让移动。

## 安装与签名：App Group

本应用需要一个 **App Group** 才能工作：worse_query 通过应用的 group 容器请求访问权限。签名工具必须给它一个 App Group，应用用的是实际收到的那个，名字无所谓。启动时如果显示“没有 App Group”，就是签名工具把它丢了。

- **AltStore、SideStore 或 Impactor + Apple ID**（免费或付费）：会自动创建 App Group，最省事。
- **Sideloadly 不加 App Group**，用它签会报“没有 App Group”。
- **Feather、ESign 等证书 + 描述文件工具**：描述文件里必须包含 App Group；通配符描述文件（App ID `*`）装不下，会签名失败或报“没有 App Group”。
- **自己的开发者账号**：在 Apple Developer 门户创建 App Group、带 App Groups 能力的显式 App ID 和描述文件，签名时保留 App Group 权限。

上不了 App Store，只能侧载。

## 构建

`./build.sh` 编译 arm64 二进制并用 App Group 权限临时签名，生成 `聊天记录迁移.ipa`。最低部署版本 iOS 26.0。GitHub Actions 会在每次 push 到 `main` 时构建，并把 IPA 发布到 `builds` 分支；正式版本在 Release 里附带 IPA 文件。
